# 말씀카드 설치 및 실행 안내

말씀카드는 글을 입력해 카드뉴스 이미지를 만들고 저장하는 데스크톱 프로그램입니다. 인스타그램 계정을 연결하지 않아도 카드 만들기와 PNG 저장을 사용할 수 있습니다.

## 1. 사용할 설치 방법 선택

| 가지고 있는 파일 | 사용할 방법 | Python 설치 |
|---|---|---|
| `WordCard-Setup.exe` | 2절: Windows 설치 파일 | 불필요 |
| `WordCard-Windows.zip` | 3절: Windows 압축 배포본 | 불필요 |
| 이 프로젝트의 소스 폴더 | 4절: 소스에서 직접 실행 | 3.12 이상 필요 |

**현재 저장소에는 소스와 배포본 생성 설정이 있습니다. 검증된 Windows 설치 파일은 아직 생성되지 않았으므로, 지금 소스로 실행하려면 4절을 따르세요.** 배포 파일을 만드는 담당자는 8절을 참고하세요.

Windows 10/11을 우선 대상으로 개발했습니다. macOS는 추가 검증이 필요합니다. 소스 설치 시에는 필요한 패키지를 내려받을 인터넷 연결이 필요하며, 설치 후 카드 만들기와 저장은 오프라인으로 사용할 수 있습니다.

## 2. Windows 설치 파일로 설치하기

배포 담당자에게 `WordCard-Setup.exe`를 받은 경우에 해당합니다.

1. `WordCard-Setup.exe`를 더블클릭합니다.
2. 설치 위치를 확인하고 설치를 진행합니다.
3. 설치 완료 화면에서 **말씀카드 실행**을 선택합니다.
4. 다음부터는 바탕화면 또는 시작 메뉴의 **말씀카드**를 실행합니다.

기본 설치 위치는 `%LOCALAPPDATA%\Programs\WordCard`입니다. 설치 파일은 현재 사용자 계정에 설치하도록 구성되어 있습니다.

## 3. Windows 압축 배포본으로 실행하기

1. `WordCard-Windows.zip`을 원하는 위치에 **모두 압축 풀기** 합니다.
2. 압축을 푼 `WordCard` 폴더를 엽니다.
3. `WordCard.exe`를 더블클릭합니다.

`WordCard.exe`만 다른 곳으로 옮기지 마세요. 함께 들어 있는 `_internal` 폴더 등 실행에 필요한 파일을 포함해 **폴더 전체**를 유지해야 합니다. 바탕화면에서 실행하려면 실행 파일의 바로가기를 만드세요.

## 4. 소스에서 직접 설치하고 실행하기

### 4.1 준비

- Python 3.12 이상을 준비합니다. 프로젝트의 Windows 빌드 설정은 Python 3.12를 사용합니다.
- 프로젝트 전체를 내려받거나 복사합니다. `src`, `templates`, `fonts`, `docs`, `pyproject.toml`이 함께 있어야 합니다.
- 명령은 `pyproject.toml`이 있는 프로젝트 폴더에서 실행합니다.

아래 명령은 가상환경의 Python을 직접 실행하므로, 별도로 가상환경을 활성화할 필요가 없습니다.

### 4.2 Windows PowerShell

프로젝트를 `C:\work\insta-automation`에 두었다면 다음과 같이 실행합니다. 다른 위치라면 첫 줄의 경로를 바꾸세요.

```powershell
cd "C:\work\insta-automation"
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m wordcard
```

`py` 명령을 찾지 못하지만 `python --version`이 3.12 이상으로 표시된다면, 두 번째 줄 대신 다음 명령을 사용합니다.

```powershell
python -m venv .venv
```

설치는 처음 한 번만 하면 됩니다. 다음부터는 프로젝트 폴더에서 아래 명령으로 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m wordcard
```

### 4.3 macOS / Linux 터미널

`python3 --version`으로 3.12 이상인지 먼저 확인합니다. 다음 경로는 실제 프로젝트 위치로 바꾸세요.

```sh
cd "/프로젝트/위치/insta-automation"
python3 -m venv .venv
./.venv/bin/python -m pip install -e .
./.venv/bin/python -m wordcard
```

다음 실행부터는 마지막 명령만 사용합니다. Linux에서는 GUI를 표시할 수 있는 데스크톱 세션이 필요합니다. 계정 연결에는 OS 자격 증명 저장소가 필요하며, 현재 구현은 macOS 키체인과 Linux Secret Service를 지원하도록 작성되어 있습니다. 이 환경들의 실제 계정 연결은 아직 검증하지 않았습니다.

소스 설치는 프로젝트 폴더를 직접 참조합니다. 설치 후 폴더를 삭제하거나 이동하면 실행 또는 글꼴·템플릿 로딩이 실패할 수 있습니다. 위치를 옮겼다면 새 위치에서 가상환경 생성과 설치를 다시 진행하세요.

## 5. 처음 실행한 뒤 카드 저장하기

1. **설정**에서 교회명과 필요한 경우 로고·인스타 표시 이름을 입력합니다.
2. 기본 저장 폴더를 지정하고 **설정 저장**을 누릅니다.
3. 왼쪽 입력칸에 제목과 본문을 붙여넣습니다. 첫 문단은 표지이며, 빈 줄마다 카드가 구분됩니다.
4. 템플릿과 비율을 선택합니다. 기본 비율은 4:5이며 출력 크기는 1080×1350입니다.
5. **카드 만들기**를 누릅니다.
6. 썸네일을 눌러 카드별 글·유형·성경 출처를 확인하거나 수정합니다.
7. **PNG로 모두 저장**을 누르고 폴더를 선택합니다. 선택한 위치 아래에 작업별 폴더가 만들어집니다.
8. 나중에 수정하려면 **작업 저장**으로 `.wordcard` 파일도 저장합니다. 다음 실행에서 **열기**로 이어서 작업합니다.

연습용 입력은 [사용 예시](사용_예시.txt)를 참고하세요. 성경 본문은 포함되어 있지 않으며 직접 준비한 내용을 입력해야 합니다.

| 단축키 | 동작 |
|---|---|
| `Ctrl+Enter` | 카드 만들기 |
| `Ctrl+S` | 작업 저장 |
| `Ctrl+O` | 작업 열기 |
| `Ctrl+N` | 새 작업 |

카드를 개별 수정한 후 **카드 만들기**를 다시 누르면 입력 원문으로 카드가 다시 만들어집니다. 개별 수정 내용을 유지하려면 작업 파일을 저장하세요.

## 6. 인스타그램에 게시하려면

카드 생성·저장만 사용할 경우 이 단계는 필요하지 않습니다.

1. [인스타 연결 안내](인스타_연결_안내.md)에 따라 프로페셔널 계정, Meta 앱·테스터 등록, 장기 액세스 토큰과 ImgBB 키를 준비합니다.
2. **설정**에서 토큰과 실제 만료일을 입력하고 **연결 테스트 및 저장**으로 계정명을 확인합니다.
3. ImgBB 키를 입력하고 **설정 저장**을 누릅니다.
4. 카드 1~10장을 만든 후 **인스타에 올리기**를 누릅니다.
5. 계정명·캡션·해시태그를 확인한 뒤 게시를 진행합니다.

인터넷 연결은 이 과정에 필요합니다. 프로그램은 게시 전에 PNG와 작업 사본을 로컬에 저장합니다. 실제 게시 검증은 아직 완료하지 않았으므로, 운영 계정을 사용하기 전에 별도 테스트 계정으로 확인하세요.

## 7. 실행이 안 될 때

| 증상 | 확인할 사항 |
|---|---|
| `py` 또는 `python`을 찾지 못함 | Python 설치 여부와 버전을 확인합니다. 배포본 사용자는 Python 설치가 필요 없습니다. |
| `No module named wordcard` | 프로젝트 폴더에서 가상환경의 Python으로 `-m pip install -e .`를 실행했는지 확인합니다. |
| `No module named PySide6`, `PIL`, `keyring` | 패키지 설치가 완료되지 않은 상태입니다. 인터넷 연결과 설치 오류를 확인한 후 같은 설치 명령을 다시 실행합니다. |
| 패키지 설치 중 DNS·접속 오류 | 패키지 다운로드가 가능한 네트워크인지 확인합니다. 카드 생성 기능의 오프라인 지원과 최초 패키지 설치는 별개입니다. |
| 글꼴·템플릿을 찾을 수 없다는 안내 | 소스의 `fonts`, `templates` 폴더 또는 배포본 전체가 있는지 확인합니다. 실행 파일만 복사한 경우 전체 폴더를 다시 복사합니다. |
| Linux에서 화면을 열지 못함 | 그래픽 데스크톱 세션에서 실행합니다. 화면이 없는 환경에서는 아래 명령줄 생성 방법을 사용합니다. |
| 계정 연결 시 자격 증명 저장소 오류 | OS 사용자 로그인과 자격 증명 저장소 잠금 상태를 확인합니다. 카드 만들기와 PNG 저장은 계정 연결 없이 가능합니다. |
| 글이 너무 길다는 안내 | 긴 문장에 줄바꿈을 넣거나 내용을 줄입니다. 10장을 넘으면 작업을 나눠 게시합니다. |

화면 없이 예시 카드만 생성하려면 소스 설치를 마친 후 다음 명령을 사용합니다.

Windows:

```powershell
.\.venv\Scripts\python.exe -m wordcard --text "docs/사용_예시.txt" --output output --template light --ratio 4:5
```

macOS / Linux:

```sh
./.venv/bin/python -m wordcard --text "docs/사용_예시.txt" --output output --template light --ratio 4:5
```

예시 입력은 PNG 4장을 생성합니다. 결과는 `output` 아래의 날짜·제목별 폴더에 저장됩니다. 직접 만든 입력 파일은 UTF-8로 저장하세요.

## 8. 배포 담당자: Windows 실행 파일 만들기

이 절차는 Windows에서 진행합니다. 일반 사용자에게 Python 설치를 요구하지 않는 배포본을 만드는 과정입니다.

4.2절의 가상환경을 준비한 뒤 프로젝트 폴더에서 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm packaging/wordcard.spec
```

생성된 `dist\WordCard` 폴더 전체가 압축 배포 대상입니다. 먼저 그 안의 `WordCard.exe`가 실행되는지 확인합니다.

설치 파일까지 만들려면 Inno Setup 6을 별도로 준비하고 다음 명령을 실행합니다. `iscc`가 PATH에 등록되지 않았다면 Inno Setup 설치 폴더의 `ISCC.exe`를 전체 경로로 실행하거나, Inno Setup에서 `packaging/windows.iss`를 열어 컴파일합니다.

```powershell
iscc packaging/windows.iss
```

결과는 `dist\installer\WordCard-Setup.exe`입니다. 배포 전에 Python이 없는 Windows PC에서 설치·실행·오프라인 카드 생성·저장·한글 표시를 확인해야 합니다. 현재 이 빌드와 설치 검증은 수행하지 않았습니다. 세부 확인 현황은 [검증 기록](검증.md)을 참고하세요.

## 9. 작업과 설정의 보관 위치

- **PNG 및 `.wordcard` 작업 파일:** 사용자가 선택한 저장 폴더.
- **Windows 설정·임시 저장:** `%APPDATA%\WordCard`.
- **macOS 설정·임시 저장:** `~/Library/Application Support/WordCard`.
- **Linux 설정·임시 저장:** `$XDG_DATA_HOME/WordCard` 또는 `~/.local/share/WordCard`.
- **액세스 토큰·ImgBB 키:** OS 자격 증명 저장소. 작업 파일에는 포함되지 않습니다.

작업은 1분마다 임시 저장되며 비정상 종료 후 다시 실행하면 복구를 제안합니다. 다른 PC로 옮기려면 `.wordcard` 파일과 사용한 로고·배경 이미지, 추가 템플릿도 별도로 보관하세요. 새 PC에서는 설정의 이미지 경로를 다시 지정하고 인스타 계정을 다시 연결해야 합니다.
