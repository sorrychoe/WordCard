# 검증 현황

기준일: 2026-10-05 · 환경: Linux x86_64, Python 3.13, PySide6 6.11, PyInstaller 6.22

## 자동 테스트

`python -m pytest -q` 또는 `PYTHONPATH=src python -m unittest discover -s tests -v`로 실행합니다. 테스트 12개, 모두 통과합니다. GUI 테스트 1개는 PySide6가 설치된 환경에서만 실행됩니다.

| 영역 | 확인 내용 |
|------|-----------|
| 텍스트 분석 | 문단 분리, 성경 66권 이름·약칭과 장절 표기 판정, 문장을 자르지 않는 카드 분할, 한글 어절 단위 줄바꿈 |
| 이미지 출력 | 템플릿 3종 × 비율 2종의 출력 크기와 80px 안전 여백, 미리보기와 저장 PNG의 픽셀 일치, sRGB 프로필 |
| 작업 파일 | 저장·복원, 잘못된 형식의 파일 거부 |
| 인스타 업로드 (모의 API) | 1장·2장·10장 게시, 캡션·해시태그·게시 한도 검사, 이미지 준비 실패, 토큰 오류, 통신 재시도 |
| 게시 안정성 | 최종 게시 응답이 끊기면 재요청하지 않고 확인 대기 기록 보존, 링크 조회 실패 시에도 게시 성공 유지 |
| GUI | 카드 생성·수정·저장·비율 변경 |
| 코드 품질 | 모든 함수·클래스의 docstring 존재 (AST 검사) |

실제 서비스에는 요청하지 않으며, 계정·업로드·게시 응답은 모두 모의 객체로 검증합니다.

## 실행 확인

- 명령줄 실행으로 [사용 예시](사용_예시.txt)에서 PNG 4장 생성 ([축소 미리보기](미리보기.png))
- PyInstaller로 Linux 실행 파일 빌드, 실행 파일에서 카드 생성과 GUI 시작 확인
- 글꼴 로드 후 짧은 본문 10장 생성 약 0.05초 (참고치이며 사무용 Windows PC 성능 기준은 아님)

## 남은 검증 항목

- Windows 실행 파일·설치본 빌드, Python이 없는 Windows PC에서 설치·실행·설치 용량 확인 (CI 워크플로 작성 완료)
- 실제 OS 자격 증명 저장소 연동과 토큰 자동 갱신
- 테스트 계정으로 Meta·ImgBB 실제 게시
- macOS 빌드와 키체인 연동
- 교회 담당자 2~4주 시범 운영

## 구현상 결정 사항

- **글꼴:** 나눔고딕·나눔명조(SIL OFL)를 원본 그대로 번들합니다. 템플릿의 글꼴 파일명을 바꿔 다른 OFL 글꼴로 교체할 수 있습니다.
- **강조 문법:** 선택 기능인 `**강조**`는 구현하지 않았습니다. 별표는 일반 문자로 표시됩니다.
- **10장 초과:** 경고를 표시하고 게시를 막습니다. PNG 저장과 작업 저장은 허용합니다.
- **너무 긴 문장:** 한 문장이 최소 글자 크기로도 한 장에 들어가지 않으면, 내용을 임의로 자르지 않고 줄바꿈이나 축약을 안내합니다.
