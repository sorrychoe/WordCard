# 개발 검증 기록

검증일: 2026-10-05. 환경: Linux, Python 3.13.11, 설치된 Pillow 사용.

## 추가 검증: 설치된 라이브러리로 Linux 빌드

- 사용자가 설치한 `tmp` Conda 환경에서 PySide6 6.11.2, PyInstaller 6.22.3, pytest 9.1.1 확인.
- 해당 환경에는 Pillow와 keyring이 없어, 기존 Python 3.13 환경의 패키지와 ABI3 PySide6를 재사용하는 프로젝트 내부 `.venv-linux` 빌드 환경을 구성. 원래 Conda 환경은 변경하지 않음.
- `make test PYTHON=.venv-linux/bin/python`: **12개 통과, 건너뛴 테스트 없음**. 네이티브 GUI의 카드 생성·수정·저장·비율 변경 포함.
- PyInstaller로 `dist/WordCard/WordCard` Linux x86_64 실행 파일 생성 성공.
- 생성된 실행 파일에서 예시 입력으로 PNG 4장 출력 확인.
- 생성된 실행 파일의 GUI를 Qt offscreen 모드로 시작해 5초간 실행 확인 후 종료. 화면을 보며 수행하는 수동 테스트와 실제 디스플레이 환경 검증은 별도.
- Makefile: `install`, `test`, `run`, `build`, `package` 제공. `PYTHON`으로 인터프리터 지정.
- 이 결과는 Linux 빌드 검증이며 Windows 실행 파일 빌드·설치, 실제 계정 게시는 여전히 미검증.

아래 기록은 라이브러리를 확인하기 전의 최초 검증 결과입니다. GUI·pytest 미설치 제한은 위 추가 검증으로 해소되었습니다.

## 수행 결과

- 문단·66권 이름/약칭·장절 판정, 문장 보존 카드 분할, 한글 줄바꿈 검사 통과.
- 3개 템플릿 × 2개 비율에서 출력 크기와 80px 안전 여백 검사 통과.
- 저장 PNG와 미리보기 원본의 RGB 픽셀 일치 및 sRGB 프로필 확인.
- 작업 저장/복원 및 잘못된 작업 형식 거부 확인.
- 모의 API로 1장·2장·10장 게시, 캡션·해시태그·게시 한도, 준비 실패, 토큰 오류, 통신 재시도 확인.
- 최종 게시 응답 단절 시 재요청하지 않고 확인 대기 기록 보존, 링크 조회 실패 시 게시 성공 유지 확인.
- 모든 함수·클래스의 docstring을 AST 검사로 확인.
- 실제 명령줄 실행으로 예시 4장 PNG 생성. [축소 미리보기](미리보기.png).
- 글꼴이 이미 로드된 상태에서 짧은 본문 10장 생성 약 0.052초. 사무용 Windows PC 성능이나 긴 입력 처리 시간을 보장하는 수치는 아님.

실행 명령: `PYTHONPATH=src python -m unittest discover -s tests -v`

## 아직 검증하지 못한 항목

- PySide6 설치가 불가능하여 GUI 실행 테스트 1개는 건너뜀. 외부 DNS 접근 제한으로 의존성 설치 실패. 구문 검사는 통과.
- pytest도 설치할 수 없어 pytest와 호환되는 unittest 테스트를 표준 라이브러리 실행기로 실행.
- Windows 실행 파일/설치본 생성, 깨끗한 Windows PC 실행과 설치 용량 검증. 빌드 스크립트와 CI 설정만 작성됨.
- 실제 OS 자격 증명 저장·토큰 갱신과 테스트 계정의 Meta/ImgBB 게시. 테스트 계정과 키를 사용하지 않았으며 외부 게시도 하지 않음.
- Meta 공식 문서 일부는 로그인 제한으로 본문 확인 불가. 기획서의 Instagram Login 흐름을 구현했으며 실제 계정 검증이 필요함.
- 2~4주 실제 교회 시범 운영.

## 범위 내 선택

- 선택 기능인 `**강조**` 문법은 구현하지 않음. 입력한 별표는 일반 문자로 표시.
- 10장 초과 시 경고와 게시 차단. PNG 저장과 작업 저장은 허용.
- 한 문장 자체가 한 장보다 길면 임의로 잘라 내용을 손상시키지 않고 줄바꿈/축약 안내.
- 기획서의 Noto 글꼴 다운로드가 불가능하여 OFL 나눔고딕·나눔명조를 원본 그대로 번들. 기획서의 기술 선택을 먼저 수정함.
- 기획서 예시의 문단 규칙(4장)과 개발 단계 완료 기준(6장) 충돌을 문단 규칙에 맞춰 수정함.
